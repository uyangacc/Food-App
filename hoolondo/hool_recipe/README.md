# Хоолны жорын апп (зөвхөн Flutter)

Backend шаардахгүй. Бүх өгөгдөл (хэрэглэгч, жор, зураг, дуртай, хөргөгч, token) төхөөрөмж дээрээ
`shared_preferences`-ээр хадгалагдана. Энэ апп худалдаа наймаа хийхгүй, үнэ, зардал харуулахгүй.

## Ажиллуулах

Төслийн үндсэн хавтсанд (`pubspec.yaml` байгаа газар):

```
flutter create .
flutter pub get
flutter run -d chrome --web-port=5000
```

**Chrome дээр `--web-port=5000` заавал өгнө.** Тэгэхгүй бол ажиллуулах бүрт порт солигдож,
хөтчийн хадгалалт тусдаа болсноос бүртгэл, жорууд алга болсон мэт харагдана.

## Боломжууд

| Боломж | Хаана |
|---|---|
| Утасны дугаараар бүртгүүлэх, нэвтрэх, token | `auth_page.dart`, `api.dart` |
| Жор нэмэх, засах, устгах | `recipe_form_page.dart`, `recipe_detail_page.dart` |
| Өөрийн зураг оруулах | Жор нэмэх/засах формд "Зураг оруулах" (800px JPG болгож жижигрүүлж хадгална) |
| Орцыг нэр + хэмжээгээр оруулах | `recipe_form_page.dart` |
| Хөргөгчийн орцоор хийж болох хоолыг шүүх | `fridge_page.dart` |
| Ач тус, тэжээллэг чанар | `recipe_detail_page.dart` |
| Нэрээр хайх, ангиллаар шүүх | `recipes_page.dart` |
| Дуртай | Жорын зүрх дээр дарна, хэрэглэгч бүрт тусдаа |

## Анхаарах зүйл

- Анхны 7 жишээ жорыг хэн ч засаж, зураг нь солиж, устгаж болно. Өөр хэрэглэгчийн нэмсэн жорыг засах боломжгүй.
- Зураг хөтчийн хадгалалтад (ойролцоо 5 МБ) орох тул олон зураг оруулбал зай дүүрч болно.
  Тэр үед апп "Хадгалах зай дүүрсэн" гэж мэдэгдэнэ.
- Android дээр зураг сонгоход нэмэлт тохиргоо шаардлагагүй. iOS дээр `Info.plist`-д
  `NSPhotoLibraryUsageDescription` нэмнэ.
- Тэжээллэг чанар, ач тусын мэдээлэл нь ерөнхий, ойролцоо тооцоо. Эмнэлгийн зөвлөгөө биш.
- Бүртгэл, token нь зөвхөн тухайн төхөөрөмж, хөтөч дээр хадгалагдана.
